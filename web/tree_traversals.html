1. Java Code

TreeTraversals.java 
void inorder(Node node) {
    if (node == null) return;
    inorder(node.left);
    visit(node); // Left → Root → Right
    inorder(node.right);
}

void preorder(Node node) {
    if (node == null) return;
    visit(node); // Root → Left → Right
    preorder(node.left);
    preorder(node.right);
}

void postorder(Node node) {
    if (node == null) return;
    postorder(node.left);
    postorder(node.right);
    visit(node); // Left → Right → Root
}

void levelOrder(Node root) {
    if (root == null) return;
    Queue<Node> q = new LinkedList<>();
    q.add(root);
    while (!q.isEmpty()) {
        Node curr = q.poll();
        visit(curr);
        if (curr.left != null) q.add(curr.left);
        if (curr.right != null) q.add(curr.right);
    }
}

Why does this line run?

DFS traversals use the call stack to explore subtrees deeply, while BFS uses a FIFO queue to visit level by level.

Remember

All four traversals visit every node exactly once in O(n) time. Badges on nodes show their visit order (1, 2, 3...).
